# meriden.com.ar

Sitio web de **Meriden — Consultoría empresarial**. HTML y CSS estático, sin dependencias ni build, publicado con GitHub Pages.

```
index.html              página principal (una sola página con secciones)
404.html                página de error
assets/css/styles.css   estilos (paleta y tipografías arriba de todo)
assets/img/             logo y símbolo (reemplazables manteniendo el nombre)
CNAME                   dominio propio para GitHub Pages
```

Para verlo en tu compu, abrí `index.html` en el navegador.

Publicación y configuración del dominio: ver [GUIA-DOMINIO.md](GUIA-DOMINIO.md).
